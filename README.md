# Grassr00tz 2026

Presentation and lab materials for the **2026 Midwest OT Cybersecurity Summit**.

## About

This repository contains the speaker materials for a talk and hands-on lab focused on operational technology (OT) and industrial control system (ICS) cybersecurity. The session covers impact in OT environments, the role of failsafes and engineering controls, SCADA design considerations, and a practical Modbus exercise.
